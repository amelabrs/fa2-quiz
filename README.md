# FA-II Practice

Interactive practice quizzes for Prajval Vidyanikethan School's Class 1 Formative Assessment II (2026-27), styled after [LetterBrain](https://github.com/amelabrs/letterbrain).

- **English** (`english/`) — "Tina's Friends": word choice, rhymes, true/false, am/is/are, picture description, and a "who am I" riddle.
- **EVS** (`evs/`) — "My Body, My Home": word choice, matching the senses, true/false, and naming body parts from picture close-ups.

Wrong answers don't advance the quiz — the child picks (or types) again until they get it right.

Live at: https://amelabrs.github.io/fa2-quiz/
